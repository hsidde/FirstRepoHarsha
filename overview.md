# FeaturesOfJobForYouCollege
* Uploading documents and profiles - Allows users to upload information that can help user recieved personalized job recommendations
* Links to job applications - Along with listing possible job oppurtunities, application provides users with links to those job application for convinience
* Can allow career advisors to access - Students can invite career advisors via a sharable link so that they can oversee the process and provide advice to students
* Store academic data to your profile- Can store information like GPA and what bachelors and field student is studying to get more personalized recommendations
* Track application status -  Can provide status of applications (e.g. submitted ) to easily track how far each application has been reviewed
